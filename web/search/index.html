01 · Préparer la demande

La demande contient des titres, URL et notes chiffrées de votre bibliothèque. Elle ne contient ni le texte des articles ni vos descriptions personnelles.

Voir la demande et le format attendu

02 · Importer sa réponse

Collez l’objet JSON complet. Le format est contrôlé avant enregistrement ; les URL déjà connues sont ignorées.

Après acceptation, lancez npm run archive dans le dépôt : les sources manquantes seront récupérées, puis les textes, rapports et index actualisés. L’import JSON ne lance aucun téléchargement.
